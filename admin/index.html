Sign in with a GitHub access token

How do I get a token? (2 minutes, one time)
  1. Open GitHub → New fine-grained token.
  2. Token name: Colletti Labs Admin. Expiration: 90 days.
  3. Repository access: Only select repositories → pick (and if you created it).
  4. Permissions → Repository: Contents: Read and write. Optional: Actions: Read-only (shows publish status).
  5. Click Generate token, copy it, and paste it above.

Only people whose token can write to the repository can sign in. The token stays in this browser and is sent only to GitHub.
